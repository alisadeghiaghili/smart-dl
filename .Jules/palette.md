## 2025-02-18 - Tooltips & Empty States
**Learning:** Adding `help` tooltips to complex Streamlit fields greatly clarifies advanced features without cluttering the UI, while dynamically disabling buttons depending on state (like an empty queue) prevents user errors and confusing non-actions.
**Action:** Always add inline help for advanced settings and disable destructive/action buttons when they shouldn't be interactable based on the current context.
